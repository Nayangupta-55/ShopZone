# ShopZone

A modern Single Page E-Commerce Application built with **React**, **React Router DOM**, **Context API**, and **Tailwind CSS**. ShopZone demonstrates enterprise-level frontend architecture including client-side routing, global state management, persistent shopping cart, mock authentication, and protected routes.

## Live Features

- Multi-page SPA with React Router
- Dynamic Product Details using URL Parameters
- Global Shopping Cart using Context API
- Guest Authentication
- Protected Checkout Route
- Responsive Mobile-First UI
- Modern Tailwind CSS Design
- Loading & Error States
- Aggregate Cart Pricing

## Tech Stack
